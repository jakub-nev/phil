## Lesson -> edit

This is the second time a GDP bracket got worse, not better, by narrowing
sd close to release on a single late soft qualitative source (central-bank
"stagnation"/"pause" language) without a hard-data anchor backing the
narrower band — the first was the US Q3 GDP advance (RETRO-20261029-1600,
GDPNow 3.5 blended down to 3.2 on NY Fed's 2.67, actual 3.4). Edited
`strategy/playbook.md` (the RETRO-20261029-1600 passage, ~line 5691) to add
this second instance and flag the shared direction: don't narrow an
already-reasoned sd on a soft-only source; prefer re-centring over
re-narrowing when the new evidence is qualitative. n=2, still no hard
quantitative rule — watching for a third instance.
